# The Creature's Features

A 2D local multiplayer fighting game made in Godot.


## Running the project

1. Download and install Godot 4.7.
2. Open Godot and import this project folder.
3. Press the Play button in the editor to run it in the debugger.

## Controls

**Player 1**
- Move: WASD
- Attack buttons: I, O, Space is jump

**Player 2**
- Move: Arrow keys
- Attack buttons: . (period), / (slash), Shift is jump 

## Testing a round win and the upgrade screen

To force a round win without playing a full round out, press 1 to give player 1 the win or 2 to give player 2 the win. This takes you to the upgrade selection screen. On that screen either player's inputs will move through the cards, select with space bar.

## About

Two players fight in short rounds. Losing a round gives you upgrades to pick before the next one, so the fight keeps escalating instead of one player running away with it.
